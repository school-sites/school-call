연결 중
화면이 꺼지지 않게 하려면 한 번 눌러 주세요

브라우저는 사용자가 화면을 한 번 눌러야 꺼짐 방지를 허락합니다. 아무 곳이나 눌러도 됩니다.

그래도 화면이 꺼진다면 기기 설정을 바꿔 주세요
  • 아이패드·아이폰 설정 → 디스플레이 및 밝기 → 자동 잠금 → 안 함
  • 안드로이드 태블릿 설정 → 디스플레이 → 화면 자동 꺼짐 → 가장 긴 시간 (일부 기기는 개발자 옵션의 ‘화면 켜짐 상태 유지’)
  • 윈도우 노트북 설정 → 시스템 → 전원 및 배터리 → 화면 및 절전 → 모두 안 함, 충전기 연결
  • 맥북 시스템 설정 → 잠금 화면 → ‘전원 어댑터 사용 시 디스플레이 끄기’ → 안 함
  • 갤럭시 탭 설정 → 디스플레이 → 화면 보호기 끄기, 설정 → 디스플레이 → 화면 자동 꺼짐 → 가장 긴 시간
  • 아이패드 화면 고정 설정 → 손쉬운 사용 → 사용법 도우미 켜기 → 호출판에서 측면 버튼 3번 눌러 시작 (다른 앱으로 못 나가게 고정)
  • 크롬북 설정 → 기기 → 전원 → 유휴 상태일 때 ‘디스플레이 켜 두기’

노트북 덮개를 닫거나 이 탭을 다른 탭으로 가리면 꺼짐 방지가 풀립니다. 이 탭을 맨 앞에 띄워 두세요.

본부에서 이 기기 번호를 초기화했어요. 번호를 다시 골라 주세요.
